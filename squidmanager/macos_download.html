Install on macOS

SquidManager for macOS

Since the application is not signed (I don't want to pay the $99/yr) you will need a manual step in the console to allow it to run.

Download v1.3 for macOS ← Back to SquidManager
  1. Download SquidManager_osx.zip — the app will be automatically extracted during download
  2. Use the following command to allow it to run:xattr -d com.apple.quarantine ~/Downloads/SquidManager.app
  3. You can now run it. You can move it to the Applications folder if you desire.
